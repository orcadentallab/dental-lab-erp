# لوحة المصمم: التسليم والمعاينة مستقلان عن تفعيل QC

قرار المالك في 5 نوفمبر: المصمم يسلم رابطًا أو ملف تنفيذ ومعاينة HTML من بوب أب داخل لوحة التحكم، ويشاهد التصميم منها دون زيارة Design QC، وتظهر التعليمات الفنية بجانب الحالة. يجوز تخطي HTML بسبب مكتوب. النشر وتغيير الإنتاج ليسا ضمن التفويض.

## النتيجة المحلية

- نفس نموذج التسليم يعمل مع QC موقوف أو مفعّل. الافتراضي إرفاق HTML، ويوجد اختيار صريح «تخطي رفع HTML مع كتابة السبب». الحفظ يتطلب HTML أو سببًا غير فارغ، دون موافقة إضافية للتخطي.
- تعليمات المورد الحالية ورقم نسختها يظهران داخل صف الحالة؛ الضغط يعرض النص كاملًا. أضيف النص إلى إسقاط المصمم المقيد بالتكليف، دون إظهار المورد أو مرجعه الخاص أو إنشاء طلب HTTP إضافي لكل صف.
- زر «عرض التصميم» يفتح بوب أب للتحميل/الرابط ومعاينة HTML المعزولة، مع تعليمات النسخة وقت التسليم أو سبب عدم إرفاق HTML. لا حاجة للتنقل إلى Design QC. يُعاد فحص الإذن قبل فتح الملفات، وإعادة التكليف تظل تمنع المصمم السابق؛ نافذته تغلق عند تحديث القائمة وفقد التكليف.
- الإيقاف لا يمنع حفظ الملفات والمعاينة والنسخ. عند التشغيل تبقى بوابة المراجعة الحالية للتسليمات الجديدة كما هي؛ لا اعتماد أو مراجعة بأثر رجعي.
- أثناء إضافة اختبار يجمع تسليمًا آخر وإعادة تكليف، ظهر أن كشف الحساب التفصيلي يخفي مساهمة المصمم السابق إذا وجدت له حالة أخرى. المساهمة كانت محفوظة وقيمتها صحيحة. أُضيف إسقاط المساهمات الموجود أصلًا إلى قارئ الكشف التفصيلي، كما في الملخص، دون إنشاء أي مستحق أو حركة نقد أو تعديل Remake.

مهاجرة محلية إضافية: `20261104232934_designer_dashboard_technical_instructions.sql`، لتوسيع الإسقاط الفني الموجود فقط. لا مهاجرات إنتاج أو backfill أو نشر أو تغيير مصدر مالي.

1. افتح `http://127.0.0.1:5173/dashboard` بحساب `review_designer_old` وكلمة المرور `Local-Review-2026!`. إن بقيت جلسة قديمة، سجل خروجًا وادخل مجددًا بعد إعادة إنشاء QA.
