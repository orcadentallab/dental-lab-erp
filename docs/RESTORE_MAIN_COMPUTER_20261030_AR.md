# النقل إلى الكمبيوتر الأساسي

- `master`: نسخة الموظفين المنشورة، تشمل توافق V2 وإصلاحات البناء والأصول
  وموافقات المندوب والتقارير وقائمة حالات الإنتاج الإنجليزية.
- `codex/temporary-laptop-backup-20261030`: نسخة المصدر الكاملة المحفوظة للعمل
  الجاري، بما فيه Dr Portal. ليست فرع نشر إنتاج؛ لا تدمجها كاملة في master.
- بعد clone استخدم `git fetch origin` ثم `git switch master` و`git pull --ff-only`
  للحصول على الإنتاج. لاستكمال البوابة استخدم checkout منفصلًا لفرع النسخة
  الاحتياطية مع الاحتفاظ بإصلاحات master الأحدث عند تجهيز الإصدار.
- `.env` و`.env.production` وأي نسخ قواعد بيانات/مفاتيح لا تُرفع إلى GitHub؛
  انقل الإعدادات الخاصة بشكل منفصل وآمن. مجلدات dependencies وdist مؤقتة
  ويعاد إنشاؤها بتثبيت الحزم والبناء.
- فحص تاريخ إنتاج Supabase بتاريخ 30 أكتوبر أكد أن migrations V2 وmigration
  المندوب `20261030000000` مطبقة. الـ13 المعلقة تخص حزمة البوابة واعتمادياتها،
  من `20261004000000` إلى `20261011060000`. يشمل ذلك تحديث الأمن المشترك
  وتعريف مزامنة الإنتاج القديم؛ لا تطبّق الحزمة دون تجهيز توافقها مع V2.
- لا تشغّل `deploy.ps1` من فرع النسخة الاحتياطية: يجمع العمل كله ويشغل db push.
